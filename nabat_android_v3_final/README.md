# اپلیکیشن اندروید نهایی سامانه نَبَط (نسخه ۳)

## قابلیت‌های نسخه نهایی (v3.0-final):
- **رفع قطعی مجوز زمان اجرای دوربین (Android 6–15):** درخواست خودکار مجوز `CAMERA` قبل از باز کردن دوربین و عکاسی مستقیم از سونوگرافی و مدارک بیمار (به همراه پشتیبانی از گالری چندتایی و میکروفون).
- **آیکون اختصاصی نَبَط (@DAROO100):** تولیدشده در تمام ۵ چگالی استاندارد (`mdpi` تا `xxxhdpi`) به همراه Adaptive Icon برای نمایش بدون بریدگی روی گوشی‌های سامسونگ و شیائومی.
- **ارسال مستقیم فایل واقعی PDF قطع A5 در ایتا:** ساخت فایل PDF با نام بیمار و باز کردن مستقیم اپلیکیشن ایتا (`ir.eitaa.messenger`) جهت ارسال.
- **همگام‌سازی خودکار و کارکرد آفلاین:** ذخیره پرونده‌ها و عکس‌ها در حالت قطعی اینترنت و ارسال خودکار پس از اتصال.
- **تغییر آدرس سرور از داخل خود برنامه:** دکمه یک‌کلیکی برای جابجایی بین پیش‌نمایش پلسک و دامنه رسمی `https://nabat.daroo100.com/factor.html`.

## نحوه ساخت سریع APK در مخزن فعلی گیت‌هاب (`teb`):
1. فایل فشرده `nabat_android_v3_final.zip` را روی لپ‌تاپ از حالت فشرده خارج کنید.
2. وارد مخزن `teb` در گیت‌هاب شوید و از بخش **Add file -> Upload files**، پوشه **`nabat_android_app`** را بکشید و رها کنید و دکمه **Commit changes** را بزنید.
3. وارد تب **Actions** شوید؛ پس از ۲ دقیقه فایل آماده نصب را از بخش Artifacts دانلود و روی نسخه قبلی روی گوشی نصب کنید.
