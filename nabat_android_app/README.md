# اپلیکیشن اندروید سامانه نَبَط (نسخه آزمایشی متصل به پلسک)

این پروژه به صورت پیش‌فرض به آدرس پیش‌نمایش پلسک متصل است:
`http://185.173.106.117/plesk-site-preview/nabat.daroo100.com/factor.html`

## قابلیت‌های داخلی اپلیکیشن:
- چاپ و خروجی مستقیم **PDF در قطع A5 عمودی** (هماهنگ با دکمه چاپ فاکتور در سامانه)
- دکمه **ارسال مستقیم در ایتا** (Share Sheet بومی اندروید)
- پشتیبانی کامل از **دوربین و گالری** برای پیوست عکس سونوگرافی و آزمایش
- پشتیبانی از **حالت آفلاین** (کش داخلی + IndexedDB)
- **تغییر آدرس سرور از داخل خود برنامه** (در تب تنظیمات، دکمه طلایی «تغییر آدرس سرور اپلیکیشن اندروید» وجود دارد تا پس از فعال شدن دامنه رسمی `https://nabat.daroo100.com/factor.html`، بدون نیاز به ساخت مجدد APK، آدرس را تغییر دهید).

## ساخت سریع فایل APK بدون نصب Android Studio (با GitHub Actions):
1. یک مخزن (Repository) جدید در سایت `github.com` بسازید.
2. محتویات داخل این فایل ZIP را در آن آپلود (Upload files) کنید.
3. وارد تب **Actions** در بالای مخزن شوید؛ پس از ۲ دقیقه یک فایل آماده دانلود به نام **`Nabat-Trial-APK`** (حاوی فایل نصبی `.apk`) ساخته می‌شود.

## ساخت با Android Studio (در صورت نصب روی لپ‌تاپ):
پروژه را در Android Studio باز کنید و از منوی بالا گزینه **Build -> Build Bundle(s) / APK(s) -> Build APK(s)** را بزنید.
